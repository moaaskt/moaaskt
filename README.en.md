## 👨‍💻 About me


I'm a Full Stack Developer with hands-on experience in web application development, primarily using **PHP, CodeIgniter, and REST APIs**. My experience includes business logic, relational databases, service integrations, and maintaining applications in production.

Through personal projects, I'm expanding my skills in **JavaScript, TypeScript, React, Node.js, and Go**, exploring different approaches to application development, code organization, and service communication.

I also work with **Docker, PostgreSQL, Redis, and asynchronous job processing**, with projects involving artificial intelligence and process automation.

My background also includes **IoT and home automation**, with projects using ESP32, RFID, sensors, actuators, Firebase, and mobile applications built with Flutter.

I enjoy understanding the problem before choosing a solution, building features end to end, and developing software that is well-structured, secure, and maintainable.

**Areas of interest:** Back-end Development, REST APIs and Integrations, Software Architecture, Asynchronous Processing, SaaS, Artificial Intelligence, and IoT.oco é desenvolver soluções completas, com código organizado, integrações eficientes e arquitetura que facilite a manutenção e a evolução dos sistemas.
